# 🤖 Agente Tático de IA Local (Llama 3.2)

Um agente de inteligência artificial de terminal 100% offline e local, rodando via **Ollama** e **Llama 3.2 (1B)**. Desenvolvido para executar em hardware padrão sem custos de API ou dependência de internet.

---

## 🚀 Destaques do Projeto

- **Privacidade Total:** Processamento local sem envio de dados para servidores externos.
- **Custo Zero:** Execução sem consumo de tokens de APIs pagas.
- **Execução Offline:** Funciona sem conexão com a internet.
- **Leveza:** Otimizado para rodar em CPUs comuns com consumo em torno de 1.5 GB de RAM.

---

## 🛠️ Pré-requisitos

1. **Ollama instalado:** [Baixar Ollama](https://ollama.com/)
